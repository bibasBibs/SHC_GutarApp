Guitar Trainer Game

Компьютерная игра-тренажёр для обучения игре на гитаре с элементами геймификации и встроенным тюнером. Проект предназначен для самостоятельного обучения и разработан в рамках учебной работы по информатике.

Описание

Приложение представляет собой настольную программу под Windows, объединяющую три основных режима:

Тюнер — определение частоты звука и контроль точности исполнения;

Игровой режим — обучение через игровой процесс;

Теория — библиотека справочных материалов по основам музыки.

Программа анализирует звук гитары в режиме, близком к реальному времени, и предоставляет пользователю наглядную обратную связь. Проект распространяется бесплатно.

Возможности

Захват аудиосигнала с микрофона или звуковой карты;

Выбор устройства ввода и входного канала;

Распознавание нот и отклонения в центах;

Поддержка различных гитарных строев;

Игровой режим и теоретическая библиотека;

Сохранение пользовательских настроек (SQLite).
